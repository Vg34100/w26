## Workshop Overview

- Focus on **story organization** stage of data storytelling.
- Introduce **“through line”** – the core message that ties every slide together.
- Use a **storyboard** format: frame‑by‑frame layout, like movie scenes.
- Goal: each frame supports the takeaway; avoid irrelevant “information dump.”

## Data Storytelling Process Recap

- **Identify**: explore data, find insights.
- **Organize**: rearrange findings into a coherent narrative.
- **Present**: share story, collect feedback.
- Emphasize relevance of each piece to the main message.

## Storyboard Approach

- Frames = individual slides or sections.
- Can be a simple slideshow or a “martini‑glass” layout.
- Optional: add user interactions (e.g., filter thresholds).
