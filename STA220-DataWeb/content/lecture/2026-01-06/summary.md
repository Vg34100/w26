## Technical Tools Overview

- Core packages: NumPy, pandas, matplotlib/plotly for visualization
- NumPy: arrays, shape, size, slicing, broadcasting, random generation
- pandas: DataFrames, Series, indexing, selection, merging
- Use zero‑filled arrays (np.zeros) for matrix initialization
- Apply functions element‑wise (e.g., np.sin) and use vectorized operations
